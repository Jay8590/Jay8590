## 🚀 Featured Project — MyFRT (My First Responder Tool)

> A Python-based digital forensics platform built to automate the full evidence lifecycle — from live acquisition to court-ready reporting — for real-world incident response. Developed at Karpuragaurai Technologies *(private repository)*

| Feature | Details |
|---|---|
| 🧠 **Core Engine** | Python automation workflows — cut triage time by **90%** |
| 🖥️ **RAM Acquisition** | Live memory capture on Linux via Microsoft AVML |
| 💾 **Disk Imaging** | Forensic images in E01 and raw DD formats |

| ⚡ **Search** | Elasticsearch + MongoDB across **10GB+** forensic datasets |
